# Scheda Palestra

App per smartphone (PWA) per creare schede di allenamento con serie, ripetizioni, recupero e peso, seguirle in palestra con il timer del recupero e tenere lo storico.

I dati restano solo sul telefono (localStorage). Dal pulsante in alto a destra si salva e si ripristina un backup.

## Installazione
Apri l'indirizzo di GitHub Pages sul telefono:
- iPhone (Safari): Condividi → Aggiungi alla schermata Home
- Android (Chrome): menu ⋮ → Installa app
